# Практика 4: Шаблоны Django

Учебный проект по курсу «Бэкенд-разработка» — работа с шаблонами Django, статическими файлами и кастомными фильтрами шаблонов.

## Описание проекта

Проект представляет собой каталог книг библиотеки (`catalog`), демонстрирующий:
- Иерархию и наследование шаблонов (`base.html` -> дочерние шаблоны)
- Шаблонные теги и фильтры (`catalog_filters`, `price_filters`)
- Подключение и организацию статических файлов (CSS, стили каталога)
- Маршрутизацию и отображение списков (`book_list`) и детальной информации (`book_detail`)
- Модульные тесты представлений и фильтров шаблонов

## Запуск проекта

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Примените миграции:
```bash
python manage.py migrate
```

3. Запустите тесты:
```bash
python manage.py test
```

4. Запустите сервер разработки:
```bash
python manage.py runserver
```
